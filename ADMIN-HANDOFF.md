# Панель керування MOTOMIX - передача доступу

## Посилання

- Адмін-панель: https://motomix.vercel.app/admin
- Каталог: https://motomix.vercel.app/catalog
- Аксесуари: https://motomix.vercel.app/catalog/accessories

## Як працювати з товарами

1. Увійдіть до панелі керування.
2. Відкрийте **Товари** і натисніть **Додати товар** або **Редагувати** на картці.
3. У формі доступні: ID і посилання товару, назва, бренд, група, тип, ціна текстом і числом, фіксована валюта `₴ грн`, наявність, обʼєм, галерея, опис, джерело, OLX та службова примітка.
4. Кнопка **Сторінка** в картці відкриває товар на сайті для перевірки.
5. Під час редагування натисніть **Переглянути сторінку товару**, щоб відкрити поточний ID у новій вкладці.
6. У блоці **Галерея товару** додайте одне або кілька фото. Перше фото є обкладинкою. Кнопка **Зробити обкладинкою** змінює головне фото, **Видалити** прибирає фото, а перетягування змінює порядок.
7. Натисніть **Зберегти товар**. Vercel зазвичай оновлює сайт протягом 1–2 хвилин після публікації.

## Перш ніж зберігати

Власник проєкту один раз додає GitHub fine-grained токен у Vercel як змінну `MOTOMIX_GITHUB_TOKEN`. Після цього менеджери не бачать і не вводять токен у панелі керування.

## Лог перевірки

Дата: 2026-11-24

- `/admin` на production повертає HTTP 200.
- Вхід перевірено з виданими доступами.
- Картки товарів показують посилання виду `/product/<id>`.
- Перевірено 21 редаговане поле товару.
- У тесті збереження передано: ціну, числову ціну, валюту, обʼєм, галерею, джерело, OLX, службову примітку та ознаку аксесуарів.
- Перевірено поля категорії: група, іконка, фото, група аксесуарів і видимість на головній.
- Модальні вікна закриваються хрестиком, клавішею Escape та кліком по затемненому фону.
- Перевірено desktop 1440 px і mobile 390 px: без горизонтального скролу та помилок JavaScript.
- Перевірено сценарій з секретом Vercel: збереження проходить без token у браузері.
- Перевірено сценарій без секрету: панель показує інструкцію та не відправляє зміну.
- Перевірено кнопку перегляду сторінки товару: URL оновлюється під час зміни ID.
- Перевірено валюту в формі: `₴ грн`, поле не вимкнене й не виглядає недоступним.
- Повторно перевірено desktop 1440 px і mobile 390 px після останніх змін.
- Перевірено галерею: додавання кількох фото, URL, зміна обкладинки, видалення та порядок без горизонтального скролу.
