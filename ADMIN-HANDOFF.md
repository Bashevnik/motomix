# Адмін-панель MOTOMIX - передача доступу

## Посилання

- Адмін-панель: https://motomix.vercel.app/admin
- Каталог: https://motomix.vercel.app/catalog
- Аксесуари: https://motomix.vercel.app/catalog/accessories

## Як працювати з товарами

1. Увійдіть до адмін-панелі.
2. Відкрийте **Товари** і натисніть **Додати товар** або **Редагувати** на картці.
3. У формі доступні: ID і посилання товару, назва, бренд, група, тип, ціна текстом і числом, валюта, наявність, обʼєм, головне фото, галерея, опис, джерело, OLX та службова примітка.
4. Кнопка **Сторінка** в картці відкриває товар на сайті для перевірки.
5. Натисніть **Зберегти товар**. Після коміту GitHub Vercel опублікує зміну автоматично.

## Перш ніж зберігати

У **Налаштуваннях** вставте GitHub fine-grained token для `Bashevnik/motomix` з правом `Contents: Read and write`. Він потрібен для запису товарів і фото в репозиторій. Token зберігається тільки в поточній вкладці.

- `/admin` на production повертає HTTP 200.
- Вхід перевірено з виданими доступами.
