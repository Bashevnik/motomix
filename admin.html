Доступ до публікації

Налаштування

Token потрібен лише для запису у репозиторій Bashevnik/motomix. Він живе тільки в поточній вкладці браузера та не зберігається на сайті.

Як створити token

  1. У GitHub відкрийте Settings → Developer settings → Personal access tokens.
  2. Створіть fine-grained token для репозиторію MOTOMIX.
  3. Дайте дозвіл Contents: Read and write та вставте token вище.
