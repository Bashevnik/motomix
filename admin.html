Публікацію підключено

Зміни товарів, категорій і фотографій записуються в GitHub та автоматично зʼявляються на сайті після деплою Vercel.

Публікація потребує одноразового підключення

Токен більше не вводиться в панелі керування й не зберігається у браузері. Його один раз додає власник проєкту в секрети Vercel.

  1. Створіть fine-grained токен GitHub лише для Bashevnik/motomix.
  2. Надайте дозвіл Contents: Read and write.
  3. У Vercel → Project Settings → Environment Variables створіть MOTOMIX_GITHUB_TOKEN і вставте токен.
  4. Зробіть Redeploy. Після цього усі менеджери працюватимуть у панелі без токена.

Детальна інструкція: ADMIN-SETUP.md.
